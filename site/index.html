SaViMAE

Saliency-aware masking for VideoMAE. VideoMAE hides random spacetime patches. SaViMAE first computes a cheap saliency map, then masks salient and background patches at different rates, so the visual budget tracks where the action is.

The idea

Masked video autoencoders work because video is redundant: hide 90%+ of the patches and the model can still reconstruct them. Uniform random masking treats every patch the same, though. A static sky patch and a patch of a moving hand count equally.

SaViMAE splits the 16×16 patch tokens into salient and non-salient groups, based on a per-frame saliency map, and gives each group its own mask ratio:

0.85mask ratio, salient patches
--salient_mask_ratio
0.95mask ratio, non-salient patches
--nonsalient_mask_ratio

Both values are the defaults in VideoMAE/run_mae_pretraining.py and the values used by the scripts in scripts/. More of the salient region stays visible to the encoder. The background is masked almost completely, since it is the easiest part to fill in.

Method

How it differs from VideoMAE

VideoMAE (Tong et al., 2022)SaViMAE
MaskingTube masking: one random 2D mask repeated over time, ratio 0.9–0.95Saliency-conditioned: separate ratios for salient and background tokens
Extra inputNonePrecomputed per-video patch saliency (.npy)
Saliency model—Hand-crafted contrast saliency. No pretrained network, no RGB-D model
Backbone, decoder, lossViT + lightweight decoder, MSEUnchanged (upstream code)
Compute targetMulti-GPU clustersCPU-only HPC nodes via Slurm

Credit: the model, pretraining engine and most of VideoMAE/ are from MCG-NJU/VideoMAE by Zhan Tong, Yibing Song, Jue Wang and Limin Wang, “VideoMAE: Masked Autoencoders are Data-Efficient Learners for Self-Supervised Video Pre-Training” (NeurIPS 2022). SaViMAE adds the saliency pipeline in SaVi/, the utilities in scripts/, and the saliency-aware data path and CPU changes inside VideoMAE/.

Implementation note. The repo contains two versions of step 4. SaVi/saliency_masking_generator.py applies the ratios per group exactly as described above. The class the training run uses, DataAugmentationForSaViMAE in VideoMAE/datasets.py, works differently. It fixes a total budget of 0.95 × tokens and gives 85% of that budget to salient tokens, then tops up from the rest. When salient tokens are scarce, they all end up masked. Training setup

DataUCF101, pre-extracted to JPEG frames. The full list in the repo has 13,034 videos; a 1,000-video subset list is also committed
Modelpretrain_videomae_base_patch16_224 (ViT-B, patch 16, tubelet 2)
Clip16 frames, sampling rate 4, 224×224 → 8×14×14 = 1,568 tokens
Masking--mask_type savi, salient 0.85, non-salient 0.95
Batch / epochs2 / 30 (README command)
HardwareCPU only (--device cpu), submitted as Slurm jobs on Dartmouth HPC (Discovery cluster / Polaris)
